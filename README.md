# MicroFE

Boilerplate microfrontend berbasis React, TypeScript, dan Module Federation.

## Cakupan

- Shell untuk layout dan navigasi.
- Satu remote contoh dengan widget dan screen sederhana.
- Shared dependencies untuk React.
- Package UI dan kontrak integrasi.
- Loading, error boundary, dan konfigurasi remote.
- Script development/build dan CI.

## Status

Kode boilerplate belum diimplementasikan. Perintah setup dan penggunaan akan ditambahkan setelah implementasi dan verifikasi.
